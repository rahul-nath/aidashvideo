# Verification matrix (frozen at Milestone 0, revised 2026-10-21)

Every requirement, invariant and GP-01 step maps to an owning module, an implementation milestone (numbering per [../design/README.md](../design/README.md)), a positive control, a refusal/failure test, a fixture ([fixtures.md](fixtures.md)), the verbatim expected result from [../design/milestone-6.md](../design/milestone-6.md) and the retained evidence location. Evidence lives in the local store `var/evidence/m<N>/<ID>/` (git-ignored; keep it outside ephemeral checkouts, see [commands.md](commands.md) §0) and is summarised in `docs/evidence/milestone-<N>.md`. Commands: [commands.md](commands.md). Owners: [contracts.md](contracts.md), [implementation-plan.md](implementation-plan.md).

## Ownership (identical to contracts.md and implementation-plan.md)

### Responsibility owners (bound once)

| Responsibility | Owner module |
| --- | --- |
| project domain | `aidashvideo.project` |
| canonical admission | `aidashvideo.ledger` |

Head-write rule: only `aidashvideo.ledger` writes project heads, operation events, idempotency records and job/effect intents, inside one SQLite transaction; `aidashvideo.mltworker` and `aidashvideo.client` cannot write project heads.


## Quality thresholds (verbatim from milestone-6.md)

- V03: "caption/mask error at most one output frame on exact synthetic fixtures; A/V drift at most one output frame over a ten-minute fixture"
- V06: "at least 95% of nominated word boundaries within 100 ms"
- V08: "Median mask IoU at least 0.90 and fifth percentile at least 0.80 on agreed annotated visible-subject frames for text/visual selections, corrections and multi-object cases"
- V15: "duration within one output frame"; "synthetic audio agrees within one sample before lossy encoding"
- V16: "integrated loudness within 1 LU and measured true peak at or below -1 dBTP"
- Interactive performance: "The agreed 1080p30 core fixture's cached-analysis ten-second changed range must preview within fifteen seconds on the qualified host"
- Measured separately on the named host (M6): edit admission and queue delay; model load; first usable fresh-frame mask; full-range masks; cached/uncached preview; full-export throughput; RAM/VRAM/scratch use; cache hits; SAM 3.1 cold load, residency, full source-PTS coverage and durable-mask reuse without inference; MLT preview startup, seek latency, buffer depth, dropped frames, sustained playback rate.
